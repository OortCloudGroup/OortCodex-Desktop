## 新增 CLI 一键安装脚本（scripts/install-cli.*）

- 需求：一键执行 `npm install -g https://myoumuamua.com/mystatic/aistudio/oortcodex-cli-<版本>.tgz`，
  版本默认 0.0.1 可用变量控制；安装前校验 Node 必须为 24.14.0；需覆盖 bash / cmd / PowerShell。
- 交付文件（与 `update-latest.ps1` 完全独立，未改动它）：
  - `scripts/install-cli.mjs`：核心逻辑（版本校验、URL 拼装、npm 安装、结果校验）
  - `scripts/install-cli.sh`：bash / zsh / Git Bash 入口（含 nvm 自动安装与切换）
  - `scripts/install-cli.ps1`：PowerShell 入口（含 winget 自动安装 Node，UTF-8 BOM）
  - `scripts/install-cli.bat`：cmd 入口，转调 ps1（`-ExecutionPolicy Bypass`，chcp 65001）
- 变量控制：`OORTCODEX_CLI_VERSION` / `OORTCODEX_CLI_BASE_URL` / `OORTCODEX_CLI_PKG` /
  `OORTCODEX_NODE_VERSION` / `OORTCODEX_NODE_MODE`（exact|gte），命令行参数同名可覆盖。
- 关键坑位：
  1. Windows PowerShell 5.1 读取**无 BOM 的 UTF-8 ps1 会按 GBK 解析** → 中文乱码并触发语法错误，
     因此 `install-cli.ps1` 必须带 UTF-8 BOM（仓库内旧脚本 `update-latest.ps1` 无 BOM，未改动）。
  2. Windows 上 spawn `.cmd` 必须 `shell: true`，否则 EINVAL；兜底方案是用当前 node 直接执行同目录
     `node_modules/npm/bin/npm-cli.js`，效果与 npm 等价且不依赖 PATH。
  3. 当前沙箱/工具环境下 `spawnSync` 一律 EBUSY（连 `node --version` 子进程都起不来），
     故 npm 真实安装未能端到端验证；已验证：版本校验通过/不通过、版本号格式拦截、参数与环境变量解析、
     ps1 语法与退出码、sh 入口流程。

## 脚本支持远程一键安装（自举 + 多源回退）

- 需求：脚本在 gitcode 远程仓库，希望用远程链接一行安装，不克隆仓库。
- 实测结论（重要）：GitCode 所有 raw 形式（`gitcode.com/<repo>/raw/<branch>/`、`raw.gitcode.com`、
  `/-/raw/`、`archive.zip`）都返回同一个 ~5.8KB 的 HTML 登录页（HTTP 200），**不能下载原始文件**；
  GitHub raw 本机不通；自有静态站 `https://myoumuamua.com/mystatic/aistudio/` 可达（tgz 返回 200）。
- 改造：`install-cli.sh` / `install-cli.ps1` 增加「本地无 mjs → 从远程下载」的自举逻辑，
  源顺序为 `OORTCODEX_SCRIPTS_BASE_URL` → 自有静态站 → GitCode raw → GitHub raw → jsDelivr；
  下载后校验内容非 HTML，自动跳过伪装源（已验证：4 源全失败会给出明确中文错误 exit 1，
  用本地 http://127.0.0.1:8099 起临时静态服务时自举成功并执行到 npm 探测）。
- README 两份新增「🌐 远程一键安装（无需克隆仓库）」小节：三终端一行命令、脚本源回退表、GitCode raw 不可用说明。

## 再修正：GitCode raw 需要浏览器 UA（用户实测 irm 连续 403）

- 根因：GitCode raw **拒绝非浏览器 UA**。实测同一 URL：`curl/8.x` → `403 暂不支持预览（19 字节）`；
  `Mozilla/5.0 ...` → `200`（7266 字节）。用户 `irm <url>`（默认 UA 被判为非浏览器）因此连续失败。
- 修复：sh 的 curl/wget 统一带浏览器 UA；ps1 的 `Invoke-WebRequest` 加 `-UserAgent`。
  一键命令同步改为 `curl -A "Mozilla/5.0"` / `irm ... -UserAgent 'Mozilla/5.0'`，并给出「先下载再执行」备用写法。
- 验证：加 UA 后 sh/ps1 自举均一次命中 GitCode raw 下载 mjs 并跑到 npm 探测（沙箱限制）。
- 仍待用户确认后再 push：远程 ps1 还是旧版（无 UA 处理），自举阶段会失败。
